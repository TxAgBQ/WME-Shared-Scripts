# WME-Shared-Scripts

Userscripts for the Waze Map Editor (WME) by TxAgBQ. They work in both production and beta WME and use the WME SDK.

## Scripts

| Script | What it does |
| --- | --- |
| [WME Segment Turnaround Assist](WME-Segment-Turnaround-Assist/) ([Greasy Fork](https://greasyfork.org/en/scripts/604417-wme-segment-turnaround-assist)) | Finds Texas "Turnaround" segments and matches road type, lock and routing to the frontage road. You review and save. |

This repository holds released versions only. Scripts are tested before they are copied here.

## Installing

Install a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/), then install scripts from their Greasy Fork pages. Each script's folder has its own README with details.
